# 满天星原生版

固定经典原件 `满天星.swf`（classic-016），500×400、25fps。产品为 HTML/Canvas/JavaScript：原矢量、5张原位图与原嵌入 Arial 轮廓静态转换；显式迁移球、鼠标气泡、星星、能量表、组合、难度和150星结局，没有 SWF/Ruffle/AVM/WASM 运行依赖。

- `rules.js` 按55份真实AVM1脚本表达规则。显示位置采用向零截断的1/20像素；速度、弹簧保持Number。源 `time` 是能量，未补倒计时。
- `scene.js` 连接本款71个有限时间轴及具名帧回调。帧3的 `prevFrame(); play()` 即刻执行帧2，稳态为25fps；末星触发100次原缓动，51帧加300，52帧停在分数和重玩页面。
- `renderer.js` 与 `assets/artwork.js` 保留原层级/变换、按钮各态、位图、轮廓文字和球的动态遮罩。静态Canvas绘制辅助代码由FFDec26.4.0转换、修改，遵循GPL-3.0，构建包包含完整许可证；游戏素材权利属于原作者。
- 鼠标控制气泡；手机拖动使用同一逻辑坐标。开始/重玩均在按钮松开时触发，取消或旋转释放按下状态，第二指不抢控制。
- 当前完整原文件在固定Ruffle基准实际静音：3段MP3只在不可达音库，AS引用声音变量却未创建Sound；两次原版AudioContext running均peak0。迁移保留静音，不按名字补音乐。离线证据保留原声音ID与SHA。
- 本机最高分适配原SharedObject `oristarry.ang`；原件首次 BEST 为 `false`，保持原显示。原件没有远程积分/兑换/宿主服务依赖。

离线逆向、55源脚本、保护层可复现解包、源公式差分、有限绘图矩阵、原版/鼠标/手机/独立包证据在workspace `projects/10-25-qpet-originals-release/native-full-stars/`。原外壳/内层未修改；仅供解编译的AS2分析副本不作为浏览器基准，且不进入产品。

浏览器原件只覆盖菜单、鼠标弹球、第一星、落球和自然结束；原生实际鼠标已有采星计分、自然结束/重玩及Chrome390/DPR2触摸/多指取消/旋转。离线只用输入的完整150星路线到1800分通过；不称原版或浏览器150星全通、历史Flash逐像素/相位全等、实体手机或小红书容器验收。已接入同站游戏大厅，默认进入本原生版；原版对照由独立按钮打开。
