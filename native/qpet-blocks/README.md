# Q宠搭积木（企鹅搭积木）

按固定原件迁移的原生 Canvas / JavaScript 游戏。电脑按空格投放积木，首块成功后也可点击；手机点按画面投放。每次等待4秒出现提示，10秒自动投放；偏差越小越容易连击，连续完美投放递增得分。

## 原件和实现

- 归档：QPetLover/awesome-qpet-games `b82b791a053c51d385b18d98f2d9951929240c50`，`archive/games/classic/swf/Q宠搭积木.swf`，924672 bytes。
- SHA256：`56b57345d99360c4c0a1f41586f3b07cbe81475f07edf8751993d61a6d7d1539`；800×600、24fps、AS3。
- rules.js 明确迁移 Main/MoveHand/Real_obj/Score/player 规则；visuals.js 管理这款游戏的有限显示列表、57类停帧/回待机动作和原显示矩阵。没有 SWF、AVM、Ruffle、字节码解释器或运行时网络依赖。
- 915个原矢量/字体绘图函数、9张原位图、12式原积木和6段原MP3都随包内嵌。静态Canvas提取使用JPEXS FFDec26.4.0，修改后的绘图helper遵循仓库GPL-3.0许可；原画、原声及字体权利归原作者。
- 精确媒体SHA/11条原声音事件见audio-provenance.json；绘图导出及优化记录见assets/provenance.json。

## 计时、输入与性能

x/y显示属性逐次向零截断为twip，速度和加速度保持原数值；逻辑保持24fps，4/10/2秒计时分别用独立Timer。鼠标首次投放监听在原件init中缺失，保留Space首投语义；手机tap明确适配为Space。取消、多指、边界释放、失焦和旋转清理活动指针。

原夹手和椅背glow在完整原矩阵绘制后仅裁像素滤镜ROI；有界LRU24MiB，键包含完整ROI变换、源静态子树、backing、颜色及全部滤镜参数。三层完整当前状态绘制缓存最多32MiB，不缓存规则/时间/RNG。普通rAF只在原24fps tick或指针/尺寸变化时重绘。原声背景按.5音量循环；静音暂停背景并保留位置，全局混音静音，恢复不重放旧短声。

## 外部边界和验证范围

原SendScore的QQ号输入与两个2009年积分POST不参与本地玩法；本实现不采集QQ号、不伪造上传或账号次数限制。原宿主退出调用改为返回开始页，网页大厅导航独立。原开始图中的历史活动文字作为原素材保留。

12项规则/音频测试、4284组原AS碰撞差分、6000原AS移动tick以及真实边界120块离线路线通过。Chrome另对照原菜单、首次鼠标与Space，实际测连续叠块、倾倒结算、重玩、独立计时、声音输出、390×844/DPR2真实触屏事件、多指取消与横竖屏。不是物理真机或小红书容器验收，不承诺所有环境逐像素/逐声学采样等价。ROI优化的800×600同状态整图有34个光圈边缘像素差，最大单通道3/255。
