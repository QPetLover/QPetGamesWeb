# QQ企鹅穿云

固定原件为 QPetLover/QPetGames `classical_games/swf/QQ企鹅穿云.swf`，SHA256 `1f02ce6d9affb433e95c09fd8bcd05653b1cfb9938afa1e04c0cdfe5eeb66da9`，2,789,909 bytes，800×600 / 24 fps / AS3。游戏直接运行 HTML、Canvas 和 JavaScript；原 SWF 只用于离线提取与独立校对。

## 实现与来源

- `rules.js` 显式迁移 Player/Main/Bg/Yezi/Wheel/Countdown 的规则。逻辑24 fps，Countdown实际为600ms单次Timer；显示位置写回保留1/20像素截断，纯数值速度不截断。
- `scene.js` 维护本游戏固定原时间轴、六角色、层级与对象身份，接线原帧动作和碰撞。`geometry.js` 保留f32矩阵与twip边界；不执行ActionScript字节码。
- `assets/instances.js` 来源于原XML显示列表。`assets/artwork.js` 是原静态矢量/位图与FFDec Canvas辅助代码，原按钮四态与原坐标仍保留。舞台外光圈只跳过绘制；可见滤镜仅裁小像素处理范围，逻辑/声音不跳过。
- `audio-assets.js` / `assets/audio/` 是10段原MPEG的精确载荷；`assets/sound-frames.js` 保留39条原StartSound绑定、seek/sample、左右包络等参数。BGM音量0.5，原完成重启、静音停止并按相位恢复。
- 原游戏宋体为device font，原件未嵌入字形。本版本使用独立原版校对页同份站酷快乐体2016固定字形；这是字体适配，证据见`assets/device-font-provenance.json`，不声称来自该游戏的嵌入字体。

## 操作与服务边界

空格首次起跳，撞墙后等待角度轮盘，在合适角度再次按空格；能量满后连续按空格冲刺。手机“空格 · 跳跃”按键映射同一按下/释放状态，支持多指、取消与旋转释放。

原SendScore需要QQ号及已归档腾讯HTTP积分接口，本版不发送外部请求或伪造上传成功。原按钮仍可点击，显示服务暂不可用提示；本局分数照常显示。更多游戏回到统一大厅，隐藏的原exit控件仍隐藏。

## 检查状态

已通过本地验收并纳入站点构建；线上版本以仓库部署状态为准。13项原AS/规则/声音测试通过；原版实际首跳、首墙与10分自然结算已有独立证据。修复后的候选在系统Chrome前台以正常键盘输入到322分并自然结束、同角色重玩；390×844/DPR2触摸、多指局部释放、取消、旋转释放、10分自然结束与重玩均通过。10段原声实际解码且有非零输出，声音开关恢复通过。干净单HTML在断网file://下实际开局、10分结算、原图重玩和积分不可用提示通过；ZIP入口与同一HTML逐字节一致，未另称解压包重复实玩。

桌面Canvas backing封顶原800×600，CSS比例不变；390手机仍按DPR2绘制，这是明确的显示适配。保留原24fps按帧读取空格状态的语义；测试触摸使用100ms按住，未将瞬时测试tap改成自动跳跃。浏览器正常路线未达到1000米或能量满阶段，这些分支另有离线正常输入路线证据，不能冒称真实浏览器全流程；未做物理手机、小红书容器、人耳或历史Flash逐样本音频等价验收。
