# 地下城与勇士之Q宠版

由固定企鹅版 SWF 的原素材、AS2 动作、显示列表及子时间轴迁移为 HTML / Canvas / JavaScript。源码没有 SWF 解析器、AS 字节码执行器、Ruffle、WASM 或动态执行。提取及原版对照属于离线开发工具，不进入运行包。

原件为已取回的社区文件 `QQ地下城与勇士之Q宠版`，2,689,767 bytes，SHA256 `b6f281f708ebf6342840141b6d3785dedfc26be80d59ef09fcfe0fea596cef48`，SWF9 / AS2，760×420，24fps，29主帧。尚不把“宠爱地下城”正式名称或欢乐谷入口归属当作已证实结论。

## 实现与保真

- `game-logic.js` 明确实现这款游戏的菜单、两角色、城镇对话、三关、7/9/7怪、5类AI、方向双击跑、X攻击、Z蓄力和5秒冷却、C跳跃、碰撞、血量、分数、Boss清场、出门、失败与重玩。原始普通攻击与技能命中帧分别保留。Z冷却使用原setTimeout对应的wall timer；门自动跑、冲刺碰撞先后和原双循环深度交换分别实现。
- `assets/artwork.js` 是 JPEXS26.4 的原始矢量/字体/位图绘图函数及静态分发，保留153原图。74个JPEG3保留原JPEG压缩字节及无损alpha，2个JPEG2保留原JPEG字节；1个旧式共享表JPEG和76张无损图由原标签静态导出。结算的4个动态链接头像另行提取并做闭包检查。
- `renderer.js` 选择原帧及变换，按原舞台绘制；血条遮罩单独使用原显示血量及floor百分比。铁匠、教程、箭头及GO提示保留原动画与动态alpha。菜单按输入重绘，战斗保持24fps。血条栅格缓存和直接绘图在离线12场景比较中RGB最大差2，属于透明边缘分组取整差；其余菜单/说明/两角色选择逐像素相同。这只证明缓存自身，不等同于历史Flash像素等价。
- 选人阶段66个昂贵滤镜帧按原输入去重为22个固定单元，在加载页逐组准备并显示进度；不预运行游戏或声音。缓存按实际画布尺寸、原矩阵、透明度及颜色变换区分，按原整数像素位置回贴，保留实时文字和按钮；96MiB上限、尺寸变化取消、失败重试均有测试。三个1952×1079关键帧（50/60/26）与不缓存原绘图逐像素及按钮区域相同；这不代替浏览器22组实际加载和帧率验证。989/978渐变描边仍在原全画布坐标绘制，仅末尾目标像素替换的读写范围缩至原整数边界；三个关键帧与旧完整读写逐像素相同。
- `audio-assets.js` / `audio.js` 保留18条嵌套MPEG流及2段按钮音，没有重编码。每条流有原起始帧、采样率、seek和块元数据，停帧、蓄力暂停、角色动作、恢复相位分别处理。普通音效不能从根 `-export sound` 数量推断，原件的攻击/死亡声音在子时间轴流中。
- 所有287个AS导出单元和42段文本均已读；来源与逐项证据保存在对应Playground项目，不将整套SWF/逆向导出作为网站资源。

## 原件语义中的注意项

原反编译文本 `player.blood <= 0` 不可直接照抄成 JavaScript：实际字节码使用 `Greater → Not → Not → If(跳过body)`，未定义的 `player.blood` 仍会进入失败分支。仅追加trace的原件副本运行核对了自然失血到0、回滚检查点和失败框；原生仅按这个明确分支实现 `!(player.blood > 0)`，没有引入通用虚拟机。蓄力脚本的安装帧也不等于停止帧：鬼剑士原运行在f10安装、持续停f11，松开后的首帧只恢复播放；神枪手在f12安装、首次回调为f13。城镇原脚本缺省angry，首次Z自增为NaN并自动播放，松开后置0；战斗场景按原初始化为0。神枪手正angry持续驻留13由相同结构源码实现，本轮原运行只采到城镇NaN自动播放，未将其记作驻留实证。测试侧保留来源pcode及AS，均不进入构建。另有仅trace的原件公开输入记录：原普通攻击击中后下一物理帧扣怪血；动态受伤实例按创建的逆序执行，已经排队的旧父激活回调可能覆盖刚进入的受伤状态。原生使用这款游戏的具体native回调排序，既不按Y深度猜执行序，也不引入通用AS解释器。

给定原件的积分记录及结果榜单按钮回调为空；迁移不伪造服务器、账号或排行榜数据。现有菜单榜单画面及按钮行为按该文件保留。

## 操作及构建

方向键移动，短促按下并释放左右键后再次按同方向进入跑步。X普通攻击，C跳跃；按住Z蓄力、松开发动，技能结束后5秒恢复。Enter或原对话按钮推进城镇对话。触屏按钮是输入适配，原规则及时间步不变。桌面舞台上限为原始760×420 CSS像素，高分屏仍按原DPR（上限2）绘制；短横屏沿用独立控制区布局，不降低内部采样画质。

在仓库根目录运行：

```sh
node scripts/build-native.mjs --game=qpet-dungeon
node scripts/build-native.mjs --game=qpet-dungeon --xhs
node --test native/qpet-dungeon/tests/*.test.mjs
```

网站原版对照为 `https://qpetlover.cn/QPetGames/#/play/happy-dungeon`。独立包仅为可移植静态HTML候选，不代表已上传小红书或通过真机/平台验收。
