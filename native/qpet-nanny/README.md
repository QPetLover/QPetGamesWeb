# Q宠保姆

800 × 600、25 fps 原生 HTML / Canvas / JavaScript 迁移。固定原件 classic-009，784,818 字节，SHA-256 `5068d5488c397e5a6272c8c8e62ae28db6347780c9178fcfea3dae646fa076bc`，与 awesome-qpet-games `b82b791a053c51d385b18d98f2d9951929240c50` 中 `archive/games/classic/swf/Q宠保姆.swf` 的 LFS OID 一致。

- `rules.js` 显式迁移 Main / Bonus / PopKeys 的规则；`game.js` 接原帧率、独立毫秒计时器、实例与动作生命周期。
- `assets/artwork.js` 是原符号离线提取的静态 Canvas 绘图函数，保留原矢量、位图、按钮四态与效果。`source-scene.js` 接原显示列表、当前子动画、真实篮子与物件几何。固定现代原版比较基准的显示位置量化、f32 AABB 与监听注册序单独核对。
- 11段原 MP3 全部保留，主逻辑的8个 GMusic 声音和帮助按钮的281号移入提示音分别接线。源声明的 MSPACE / MSTART 未调用，礼物使用没有额外声音；106个空流头没有有效流块。
- 数字与结算文字静态字形来自同站原版比较页实际使用的站酷快乐体，游戏原嵌入标题文字保留。

产品不包含 SWF、Ruffle、AVM、WASM、原 AS 执行器或测试 VM，也不请求外部游戏资源。SWF 仅用于离线逆向与独立对照；HTML / ZIP 包可单独运行。

保留原件规则：一次相同食物有1或2个时只送1个，连续3个以上才整批送出并增加 COMBO；送错一批只扣一次血；礼物在 HP95 时加到105而血条封顶；数组删除造成相邻物件跳过；致命漏接的结果先于最后100分惩罚捕获；旧投送批次的抵达回调可影响刚重开的新一局。原主界面的关闭按钮在所选原件未注册且落在舞台外，外层“结束游戏”是可用源关闭方法的操作适配，会以0分结束。手机按钮对应原键盘。旧“更多游戏”网址在网页中改为返回大厅，独立包不包含大厅链接。

FFDec衍生绘图 helper 按 GPL-3.0 提供可阅读源码，条款见仓库 `licenses/FFDEC-GPL-3.0.txt`；原美术、声音和字体权利仍归各自作者。

原版/原生的公开键盘操作、音频、自然结束/重玩、手机CDP触屏与旋转、单HTML仅一次网络请求的证据在工作区 native-nanny 项目。手机为 Chrome 模拟，未代表物理手机或小红书实际容器验收。Timer与帧事件恰好同刻的宿主先后、极长高难度自然局未做逐帧全序证明。本目录为待主任务统一整合的候选，未自行注册/发布。
