# Q宠爱音速 · 原生迁移版

直接打开 ZIP 根目录的 `index.html`，或单独打开 `Q宠爱音速.html`。所有画面和声音已随 HTML 内嵌，不需要 Flash 或外部运行库。源码在 `source/`；源码目录可用 `python3 -m http.server 4201 --bind 127.0.0.1` 预览，`python3 build.py` 重新生成独立 HTML / ZIP。

方向键左右移动、上跳、下蹲，斜向障碍使用两个方向键。手机屏幕下方提供可同时按下的方向按钮。声音须在点击开始后由浏览器启用。三关为糖果王国、万圣之夜、圣诞星空。

本版本从已取得的人类角色同源 SWF 迁移规则、关卡、静态绘图、原声和时间轴，再按腾讯历史截图恢复企鹅表现。菜单使用清晰的原矢量场景，轮滑、头像、鼓励和结算企鹅为参照截图补制的新素材；不再放大低清截图。原幼圆按钮字形、分数、关卡、说明和结算文字尽量复用静态原路径，缺失的企鹅专属文字采用同类字体，标题轮廓为近似复原。历史企鹅版 SWF 尚未找回，因此不能把本版本当作原始企鹅文件或像素级复原。版本身份只在页面外围说明。

旧版双乐榜、QQ 积分上传 / 兑换服务未恢复；相应按钮保留，点击后在游戏画面下方说明服务状态。分数只存在本机。暂停、手机触控、本机最高分是适配项。

规则差分、完整三关方向输入、全部 30 种关卡障碍、失败及结算绘制已做离线检查；颜色缓存在 DPR 1 / 2 比较了完整像素和按钮命中。用户已确认实际可以正常玩并出声；另以本地 Chrome 检查加载、开局、按键、暂停、重玩、实际 Canvas 和 WebAudio。手机检查使用浏览器触屏模拟，不等于物理真机；完整保真与声学逐帧等价未作保证。
