## 对照结果（2026-10-22）

使用 Ruffle 0.7.1 在桌面应用内置浏览器实际游玩。通过原版菜单进入游戏说明、棋盘，执行管道点击，观察普通连通路径的爱心移动、管道清除和 HUD 加分至 00030，等待时间耗尽后从原「再来一次」返回棋盘。原小猫干扰动画也已观察到。

上述结果是在首次网页化交付中验证的原游戏流程。整理为独立仓库后，另在本机 Chrome 实测了加载、解除静音、原始尺寸切换、中文游戏说明和开局；资源一致性与 HTTP 交付校验通过。不能把这些记录扩张为完整通关结论。证据位于 [evidence/qpet-match](../../evidence/qpet-match/)。

## 已知差异与未覆盖范围

- 两段动态中文文字请求未提供的「华康海报体W12(P)」设备字体。Ruffle 加载 Noto Sans CJK SC 后可显示中文，但字形不完全相同；SWF 已嵌入的字形不变。
